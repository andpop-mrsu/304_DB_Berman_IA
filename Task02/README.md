# Лабораторная работа №2. Разработка утилиты миграции данных и генерации базы данных

## Введение

В данном проекте спроектирован и запущен конвейер **ETL (извлечение, преобразование и загрузка данных)**, предназначенный для импорта массивов информации из структурированных CSV-таблиц в реляционную базу данных SQLite.

Специализированный Python-скрипт сканирует директорию `dataset/` и автоматически собирает итоговый файл конфигурации `db_init.sql`. Внутри этого файла последовательно выполняются:
* Команды очистки окружения (`DROP TABLE`), стирающие старые сущности при перезапуске;
* Команды развертывания структуры (`CREATE TABLE`), фиксирующие типы колонок;
* Пакетные вставки записей (`INSERT INTO`), переносящие строки из файлов.

Последующее исполнение сгенерированного файла через клиент `sqlite3` приводит к сборке готового файла базы данных `movies_rating.db`.

## Спецификация системных требований

Чтобы запустить управляющий файл `db_init.bat`, на целевой машине необходимо предварительно настроить следующий программный стек:

* **Интерпретатор Python** — сборка протестирована на версиях `3.6` и старше.
* **СУБД SQLite3** — подойдет любой стабильный дистрибутив утилиты.
* **Командная оболочка Bash** — на Unix-системах доступна из коробки, в среде Windows рекомендуется использовать терминал `Git Bash`.
* **Утилита Git** — требуется для корректной работы консольного окружения.

## Порядок проведения сборки и инициализации

Запуск пайплайна миграции выполняется одной командой в консоли:

```bash
./db_init.bat
```

Внутри командного файла зашиты два последовательных этапа автоматизации:
1. Вызывается парсер `make_db_init.py`, формирующий текстовый лог инструкций в `db_init.sql`.
2. Поток команд из `db_init.sql` перенаправляется на вход СУБД: `sqlite3 movies_rating.db < db_init.sql`, собирая таблицы воедино.

## Выходные артефакты

Успешное завершение работы консольного скрипта гарантирует появление в корневой папке `Task02/` двух новых объектов:
* Файла `db_init.sql` с полной историей SQL-транзакций для переноса данных;
* Файла `movies_rating.db`, представляющего собой готовую к аналитическим запросам локальную базу данных.
